5. Downloading an HTML editor

I researched some free HTML editors with a quick search on the internet, and saw that a program I already had installed for personal hobbies, Visual Studio Code, was one of the top picks. Loading it up it has very sleek layout options, and copilot built in for assistance. One of the coolest parts is it removes the tedious framework building for a basic HTML structure, you just need to type ! and press TAB, and it auto fills the rest. VS Code also connects to git, so I can manage my files from the application as well.
